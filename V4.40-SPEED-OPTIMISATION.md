# v4.40 — Site Speed Optimisation

## Changes
- Removed render-blocking Google Fonts `@import` from `variables.css`. Fonts now load through a stylesheet appended after document parsing.
- Changed the global logo references to a 256px optimized PNG; favicon/apple-touch icon use a 96px optimized PNG.
- Created optimized leadership card JPEG derivatives (max 900px, progressive JPEG, quality 82) while retaining the original Otunba portrait for the full-bleed leadership hero.
- Added lazy loading and asynchronous decoding to non-critical content images.
- Changed the homepage hero video to `preload="none"` and defer its initial playback request until the browser has an opportunity to paint.
- Added high-priority preload for the small homepage hero poster.
- Changed the site loader so it no longer waits for the window `load` event; it reveals after DOM paint with a short safety timeout.
- Added desktop `content-visibility:auto` to below-the-fold sections to reduce initial rendering work.

## Intent
Improve perceived load speed and reduce initial network/rendering work without changing the site's visual design, navigation, forms, or content.
