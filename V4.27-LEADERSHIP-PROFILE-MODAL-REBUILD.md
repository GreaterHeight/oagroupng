# OA Group v4.27 — Leadership Profile Modal Rebuild

## Problem identified in v4.27
The profile-contact block was rendered with `hidden` and the JavaScript explicitly hid it on every profile render. This contradicted the supplied reference design and made the interaction appear primarily as an image viewer.

## v4.27 implementation
- Dedicated two-column editorial profile window.
- Left: portrait + Profile Contact area.
- Right: Leadership eyebrow + full name/credentials + role + accent rule + Biography.
- Contact details are data-driven and are not invented; pending details show a clear placeholder until approved information is supplied.
- Three supplied portraits are wired to the correct profiles.
- Escape, outside-click, close button and focus restoration retained.
- Mobile collapses to a single column.
- No dependence on the site's generic gallery/video modal.
