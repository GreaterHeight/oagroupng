## Replacement rule
Final commissioned images should be exported in modern web formats where practical (WebP/AVIF), sized to the displayed component, compressed appropriately, and retain descriptive `alt` text. Do not use external stock-image URLs. Do not remove the `.arch-frame` wrapper; it provides the approved fallback and layout contract.
