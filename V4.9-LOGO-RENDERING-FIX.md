# v4.9 — OA Group Logo Rendering Fix

## Root cause addressed
The logo was relying on a large source PNG plus a succession of responsive
rules. That made the header logo vulnerable to flex sizing and asset handling
interactions.

## Production fix
- Created a clean, browser-safe transparent PNG from the supplied logo:
  `/images/oa-group-logo.png`
- Normalized all site header/footer/loader references to that asset.
- Added intrinsic width/height attributes to reduce layout instability.
- Made the header brand a non-shrinking flex item.
- Added explicit desktop/tablet/mobile logo dimensions.
- Protected brand assets from the generic content-image placeholder handler
  using `data-brand-asset="true"`.
- Kept the existing placeholder system for ordinary content images.
- Added deterministic loader-logo sizing.

## Responsive sizes
Desktop: 148px logo
Tablet: 132px logo
Mobile: 122px logo

The logo is intentionally not allowed to collapse, clip, or be removed by the
content-image fallback mechanism.
