# OA Group Nigeria — v4.4 Mobile Navigation & Logo Loader

## Mobile/tablet navigation
The navigation now switches to the compact hamburger layout at 960px.
The logo has no fixed minimum width on mobile and scales down, while the
hamburger remains a 44px touch target. This prevents medium-width mobile and
tablet layouts from forcing the desktop navigation or requiring zooming.

## Loading spinner / throbber
Every browser-facing HTML page now contains a site-wide loading overlay using
the supplied `/images/OAGroup-logo.png`.

The logo sits inside a restrained circular spinner. The overlay is dismissed
on the window `load` event, with an 8-second safety timeout. Reduced-motion
users receive a non-animated version.
