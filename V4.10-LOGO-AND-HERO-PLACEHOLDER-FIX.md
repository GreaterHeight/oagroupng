# v4.10 — Logo & Inner Hero Placeholder Fix

## Logo
- Reduced the header logo to a restrained 108px desktop presentation.
- Tablet: 102px.
- Mobile: 96px.
- Reduced the loading-spinner logo to 40px inside a 72px rotating ring.
- Corrected malformed `<img>` attributes from the previous build.
- The brand asset remains excluded from the generic content-image fallback.

## Inner-page heroes
Affected routes:
- `/about/`
- `/insights/`
- `/gallery/`

Their hero JPGs are intentionally not supplied in the build yet. Each now
has an explicit placeholder-image marker and a clean placeholder component.

The fallback script now checks on:
1. native image error,
2. DOMContentLoaded,
3. immediate deferred scan,
4. 250ms follow-up scan,
5. window load.

Therefore a missing hero JPG is converted to the approved placeholder rather
than leaving a browser broken-image icon.
