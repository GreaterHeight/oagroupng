# v4.6 — Full-Bleed Inner-Page Hero Fix

The inner-page hero image is now anchored to `.page-hero`, not to the centered
`.page-hero__grid` container.

## Result

`page-hero`
→ full-width/full-height hero image
→ readability overlay
→ constrained text content

The image remains a real `<img>` element so the existing placeholder-first,
image-load-error fallback system continues to work.

## Hero dimensions

- Desktop: 380px minimum
- Tablet: 330px minimum
- Mobile: 300px minimum

## Image behavior

- 100% width and height
- `object-fit: cover`
- Full hero footprint
- Dedicated 16:9 JPG assets
- Existing `.is-empty` placeholder preserved
- Responsive mobile crop
- Text-safe dark overlay

This is a CSS/layout correction. No separate CSS-background image mechanism
was introduced, so the established image swap/fallback system is not bypassed.
