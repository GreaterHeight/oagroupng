## USAGE NOTES

1. **File naming convention:** `hero-home-mixed.jpg`, `hero-home-allblack.jpg`, `hero-home-allwhite.jpg` etc.
2. **Preferred dimensions:**
   - Hero images: 1920 × 1080px minimum (16:9)
   - Blog card thumbnails: 800 × 450px (16:9)
   - Leadership portraits: 600 × 600px (1:1) or 600 × 800px (3:4)
   - OG images: 1200 × 630px
3. **Place generated images in:** `/images/` folder in the repo root
4. **Reference in HTML:** Replace `arch-frame` gradient placeholders with actual `<img>` tags inside the `.arch-frame` div
5. **Alt text:** Each prompt above describes exactly what the image contains — use a shortened version of that description as the alt attribute
