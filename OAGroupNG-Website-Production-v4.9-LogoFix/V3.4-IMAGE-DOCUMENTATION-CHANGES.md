# OA Group Nigeria — v3.4 Image Documentation Changes

The former `IMAGE-PLACEMENT-MAP.md` and `IMAGE-PROMPTS.md` have been consolidated.

`IMAGE-PROMPTS.md` is now the single source of truth for:
- visual direction
- image placement
- individual generation prompts
- article-specific prompts
- gallery-slot prompts
- homepage hero video prompt
- hero poster prompt
- negative prompts
- technical delivery rules
- crop guidance

`IMAGE-PLACEMENT-MAP.md` has been removed.

The previous prompt file contained useful high-level descriptions, but several were not detailed enough to function as production-ready generation prompts. They have been replaced with explicit, copy-and-paste generation prompts for every required website image slot.
