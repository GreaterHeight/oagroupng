# v3.7.4 — Image Placeholder / Auto-Swap System

Implemented from `Image-Placeholder-System-Explained.md`.

- Local image tags use an `onerror` removal handler.
- `/our-companies/` uses the canonical `/images/our-companies-portfolio.jpg` path.
- Its richer placeholder is hidden by default.
- A genuine image-load failure adds `.is-empty` to the parent and removes the failed image.
- When the exact JPG is later placed in `/images/`, no code change is required: the browser loads it and the failure handler never runs.
