# OA Group Nigeria — v3.5 Changes

1. Search page
   - Search button is now explicitly constrained to the same 3.25rem height as the search field.
   - Flex alignment and mobile behavior are included.

2. Footer social links
   - Social text links were converted to inline SVG icons.
   - Existing destinations/labels are preserved.
   - Icons have accessible labels and keyboard focus styling.

3. Image format
   - `.webp` image references in the visual-production documentation and HTML image references were changed to `.jpg`.
   - JPG is now the canonical supplied image format for OA Group website photography.

4. Image workflow clarification
   - Added `IMAGE-WORKFLOW.md`.
   - Generated images do NOT automatically appear in the website.
   - Each generated image must be exported as JPG, renamed to the exact specified filename, placed in `/images/`, and deployed.
   - `IMAGE-PROMPTS.md` remains the single visual-production source of truth.
