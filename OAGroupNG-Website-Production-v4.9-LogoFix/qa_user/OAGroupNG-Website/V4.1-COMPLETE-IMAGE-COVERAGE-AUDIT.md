## Coverage architecture

### Normal visual images
Each image references its final expected JPG path. If the JPG is absent,
`onerror` removes the failed image and applies `.is-empty` to the `.arch-frame`.
CSS then reveals the designed placeholder.

### Gallery lightbox
The lightbox image is populated dynamically, so it has its own placeholder
state in `.modal__media`. A failed dynamic image reveals that placeholder.

### Homepage video poster
A video `poster` is not an `<img>`, so it is covered separately. The declared
poster is preflighted with `Image()`. If unavailable, `.hero--poster-missing`
reveals the designed fallback. Reduced-motion mode also has a visual fallback.

### Logo
The supplied OA Group logo is treated as a supplied brand asset, not editorial
photography.
