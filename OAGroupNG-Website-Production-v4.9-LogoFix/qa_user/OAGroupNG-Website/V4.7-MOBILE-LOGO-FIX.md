# v4.7 — Mobile Header Logo Fix

## Root cause

The header logo was allowed to participate in the mobile flex-width
calculation and was also not explicitly protected from the site's generic
image-fallback handler.

## Fix

1. The mobile `.brand` is now a non-shrinking flex item.
2. The supplied `OAGroup-logo.png` has an explicit responsive width,
   `height:auto`, and no restrictive `max-height`.
3. The hamburger button remains a fixed 44px control.
4. The generic image-failure handler now explicitly excludes `.brand img` and
   `.site-loader__logo`, because these are supplied brand assets rather than
   content images that should be replaced by the content-image placeholder.
5. The existing placeholder-first mechanism remains unchanged for actual
   content images.

## Mobile target

At <=560px the header logo is 122px wide, with the 44px hamburger control
remaining fixed and visible.
