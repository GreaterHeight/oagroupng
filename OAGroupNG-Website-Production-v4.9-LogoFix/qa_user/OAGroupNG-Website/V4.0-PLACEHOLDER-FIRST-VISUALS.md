# OA Group Nigeria — v4.0 Placeholder-First Visuals

The broken-image state shown on `/about/` has been corrected.

Image-bearing `arch-frame` containers now use the documented rich placeholder
pattern: the placeholder is hidden by default; if the expected JPG fails to
load, the failed image is removed, `.is-empty` is applied to the parent, and
the placeholder becomes visible.

Editorial SVG stand-ins have been replaced with the final JPG filenames
specified by the site's image architecture. No empty/fake JPG files were
created.
