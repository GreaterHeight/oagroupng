# OA Group Nigeria — v3.3 Changes

## Navigation wrapping fix

The desktop primary navigation has been hardened so that:

- “Our Companies” remains on one line.
- “Talk to OA Group” remains on one line.
- Search remains an icon-only control.
- Navigation links do not wrap their labels.
- The CTA is prevented from shrinking.

The change is CSS-only and does not alter the site's navigation destinations or content.
