# v4.15 — Solutions Matrix Tabs QA

## Reported defect
Selecting another Solutions Matrix tab on the Home page did not change the
displayed panel.

## Root cause
The Home page had the complete tab/panel markup and ARIA relationships, but
the JavaScript interaction controller was absent. The first panel therefore
remained visible.

## Fix
Added a dedicated controller to `js/main.js`.

- Click changes the selected tab.
- `aria-selected` is updated.
- The matching panel is shown and all other panels are hidden.
- `aria-hidden` is updated.
- Keyboard navigation supports Arrow keys, Home and End.
- Only the active tab remains in the normal tab order.
- The implementation discovers the existing markup rather than hardcoding
  the current eight solution names.
